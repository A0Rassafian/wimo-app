🎬 WatchTogether | Watch Movies and TV Shows Together

📌 About the Project

WatchTogether is a mobile app concept designed to allow multiple people to watch movies and TV shows together at the same time.

The goal of this app is to help users watch movies and TV shows remotely with their friends while keeping video playback synchronized.

This project was designed using Figma and includes an interactive prototype.

🎯 Project Goal

The main goal of this project is to create a shared movie and TV show watching experience for people in different locations, allowing them to watch the same content at the same time without being in the same place.

✨ Planned Features

- 🎥 Group movie and TV show watching
- ▶️ Synchronized video playback and pause controls
- 👥 User interaction while watching content
- 📱 Mobile app interface design

🛠️ Tools Used

- Figma: Used to design the app screens and create the interactive prototype.
